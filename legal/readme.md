# 法务文本（模板草稿）

本目录包含面向商业发布的法律文本**模板草稿**：

| 文件 | 用途 |
|---|---|
| `privacy-policy.zh-CN.md` | 隐私政策 |
| `terms-of-service.zh-CN.md` | 用户协议（服务条款） |

**使用须知（重要）**

1. 两份文本均为**模板草稿**：正式发布（尤其是开始收费）前，必须由专业律师结合经营主体、收费方式与运营地区法规逐条审核；
2. 文中所有 `[占位符]` 需要按实际情况补全（主体名称、联系方式、退款政策、管辖法院等）；
3. 正式对外版本建议同时准备英文版（出海场景）；
4. 生成英文应用内提示时，请与「设置 → 关于」及购买流程中的表述保持一致。
