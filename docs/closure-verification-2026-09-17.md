日期：2026-09-17。基线：`2b4200b`。本轮保留 PyQt5 + QFluentWidgets，重点为参考图绑定、2～5 并发、恢复与下载。提交前已检查 GitHub main 无新增提交。

## 修复及根因

| 问题 | 根因 | 修复与证据 |
| --- | --- | --- |
| 同序号图片漏绑 | 完全/前缀命中后提前结束，不继续聚合 | 聚合所有符合规则的图片；逐图保存最高优先级的匹配方式；数字边界及自然排序回归 |
| 无序号误绑定 | 使用提示词列表行号作为序号 | 只有文件名真的含序号才走序号匹配 |
| 产品子目录串图 | 选择产品叶目录后仍递归扫描整个图片根目录 | 限定同名产品；已识别产品缺少图片目录时不退回其他产品；保留产品输出子目录 |
| 同文案重试互锁 | 等待兄弟任务时占着兄弟重试需要的提交许可 | 账本等待位于许可之外；上传/创建通过 FIFO 许可，轮询不占许可；专门互锁回归先失败后通过 |
| 多线程同时创建请求 | 原 gate 只限制退避时间，没有排他许可 | 保留 SQLite `BEGIN IMMEDIATE` 原子预约；依次上传/提交，远端生成仍可同时 2～5 条 |
| 付费任务恢复被跳过 | 当前素材缺失/策略改变时仍先执行未匹配跳过 | 同账号、同源文案未完成任务恢复原 ID；不重新创建；本地 HTTP 验证素材删除与策略改变 |
| 轮询长期无反馈 | 只输出上游百分比，默认超时 3600 秒 | 默认 7200 秒；显示累计轮询时长；进度超过 60 秒未变时提示；保留已有流动动画 |
| 转换丢信息 | H3 的概要/主体约束/配乐及 V2 禁止项/声线被删除 | 转换保留这些内容、主体和镜头；V2→H3 保持六段；记录镜头数；转换异常禁止自动换模型 |
| 超限数量不可见 | 仅提交时截取，详情与列表只显示总数 | 扫描就警告；表格显示如 9/10；详情保留所有缩略图并标记不提交图片，手工顺序有效 |
| 空自动匹配不能清空旧绑定 | `automatic_matches or matches` 将空列表当作未提供 | 区分 None 和空结果，重匹配后可正确清空并保存 |
| 未匹配策略不明确 | 手动开始时没有预检；缺产品图片目录强制跳过 | 手动开始给跳过/文生视频/取消；本次选择不改持久策略；定时/监听沿用保存策略；暂停策略对缺产品目录同样有效 |
| 激活按钮无响应 | QFluentWidgets Dialog 不存在 `viewLayout` | 使用 `textLayout`；真实按钮取消与本地测试码持久化通过；关于框品牌图标同类问题一起修复 |

目录路径依旧立即保存到 `paths.prompts/images/output`，启动自动扫描；本轮运行已有目录保存、重启自动扫描、手工共享绑定和拖拽排序回归。
