## 三、导航「点击后消失」修复

- 现象：展开状态的导航栏中，点击「设置 / 历史记录 / 工作台」，被点击项**收缩为 0 宽度并从界面消失**（点过的项逐一消失）。
- 根因：QFluentWidgets 的 `setExpanded` 展开动画以 `sizeHint` 为目标尺寸，而本主题下该值宽度为 0——点击触发的动画把节点宽度收缩到 0。
- 修复：对三个叶子导航项禁用该尺寸动画（仅保留展开状态与箭头），并在点击后做一次幂等的导航尺寸校正。
- 验证：真实鼠标点击（系统级）展开态 9/9、折叠态 6/6 全部正常；新增回归测试 `tests/test_nav_expand_click.py`（修复前红 → 修复后绿）。
