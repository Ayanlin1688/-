## 当前边界

- MiniMax-H3 服务商公开文档要求 2K/4K 的 `size` 与 `aspect_ratio` 同传，但当前实测 2K 请求返回 HTTP 422，提示二者不能同时使用。保持文档契约，未加入自动降级或自动重发付费请求。固定尺寸 1080p 可正常创建任务，真实验收采用该尺寸。
- 下载器验证传输完整性、响应类型和任务归属，不引入 FFmpeg 运行依赖。实际视频验收另外执行 FFprobe 和解码检查。
- 离线许可仍是源码明示的演示级共享密钥方案；商业发布需要独立设计签名和激活机制。
- 本轮没有重新构建或安装 PyInstaller/安装器产物；源码启动与自动测试不等同于安装包验收。
