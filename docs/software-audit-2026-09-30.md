## 本次修复

- 待确认提交：用户填写已有 `task_id` 后只查询并下载该任务，不再创建任务；用户确认服务端未创建时，仅恢复该记录对应的提示词，避免顺带提交队列中的其他任务。恢复状态采用运行时配置，不写入持久配置。
- 待确认弹窗：明确下拉框焦点与尺寸，任务 ID 输入框只在对应操作下启用，并在输入有效 ID 后同步确认按钮状态；增加真实鼠标选择回归。
- 任务工作台：运行、重新下载和关闭状态统一控制当前任务按钮；任务行可复用时只更新必要的数据，避免每次轮询都重建控件和过滤列表；列宽未变化时跳过重复布局。
- 本地历史存储：SQLite 初始化或写入失败时退回内存缓存，并尝试只读加载已有历史；仅在持久化成功时完成旧配置迁移，避免数据库不可写时误清空旧历史。
- 动效生命周期：控件销毁时停止动画并解除更新路径，定时视觉时钟容忍 Qt 对象已释放的情况。
- 全屏窗口：保留先前全屏与最大化状态同步及恢复几何位置修复。
