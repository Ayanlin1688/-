04实证详录

两条关键缺陷附可复现输出；脚本与原始日志留档（本地桩服务，零真实费用）。

CC-P2-1 · 跳过兄弟任务 → 等待任务被静默判「重复」task_execution.py:291-319

场景：队列内两个同文案、不同参考图的任务。task0 先提交成功进入 processing；task1 处于「等待兄弟收尾」循环。此时对 task0 执行跳过。预期 task1 应接管提交；实际输出（复现第 1 轮，误判批次）：

task0 submitted: True statuses: ['processing', 'uploading']
FINAL statuses: [('skipped', '已跳过'), ('duplicate', '同一提示词已有生成中的任务，跳过避免重复扣费')]
POST /videos count: 1        ← 唯一一次是 task0 的，task1 从未提交
duplicate_of: [None, '33365839cea94c1999c95985351abffd']
warning | 任务2/2：同文案任务仍在收尾，等待其结束后自动重试提交（防重复扣费）
warning | 任务1：已跳过；仅停止本地处理，远端任务可能继续执行

对照复现（第 2 轮）：task0 尚在上传阶段即被跳过时，task1 能正确接管提交（processing）——两轮对比定位出精确触发条件：兄弟「已提交后被跳过」（账本记录保持 active）时才会误判。机制：等待循环以 live_sibling() 与陈旧 outcome 组合退出、未做最终 re-reserve 刷新，落入“busy”分类分支。修复方向：循环退出后补一次最终 reserve；对「兄弟已弃用但远端未决」给出显式可恢复状态，不静默落为 duplicate。

NT-P2-2 · 非 ASCII 激活码 → TypeError 逃逸、激活无提示licensing.py:104

用户从聊天软件粘贴含中文/全角字符的内容当激活码时（高概率真实场景）：

$ python -X utf8 probe_nonascii_key.py
'YL1.abc.中文'   → !!! TypeError : comparing strings with non-ASCII characters is not supported
'YL1.abc.qQ==中文' → !!! TypeError : comparing strings with non-ASCII characters is not supported
'YL2.abc.中文'   → ValueError: 激活码校验失败（签名不匹配）   ← YL2 路径正常
'YL1.a.b'        → ValueError: 激活码格式不正确               ← 全 ASCII 正常报错

设置页激活入口仅捕获 ValueError（settings_page.py:975-977），TypeError 逃逸到 Qt 槽后被全局钩子吞掉——用户点「激活」后无任何错误提示。修复方向：parse_key 入口对签名段做 ASCII 预检并统一抛 ValueError；激活入口兜底 except Exception。

06已核查通过

评审同时记录「确认安全」的核心防线，防止反复排查同一处。

  • 提交计费安全：Idempotency-Key + allow_redirects=False（防重定向重放 POST）+ 提交不确定态保守语义（解析失败/无 task_id 的 5xx 一律禁自动重试）。
  • 跨进程账本：BEGIN IMMEDIATE 写锁、synchronous=FULL、意图永不过期、显式恢复才放行。
  • 配置持久化：同目录 mkstemp → fsync → os.replace 原子写；迁移幂等 + 失败保底；旧目录迁移的跨进程安全发布。
  • 凭据卫生：Authorization 头不落日志；api_key/log_secrets 全链路替换；调试请求体深层脱敏。（诊断包一处遗漏见 DT-P3-2）
  • 后台收尾竞态（历史修复）：_background_busy → is_running 门控 → worker.finished FIFO → sip.isdeleted 双守卫，未发现残余同类。
  • 主题系统：_THEME_CALLBACKS 弱引用 + RuntimeError 守卫；runtime_config() 深拷贝保证 _rerun_signatures 不污染持久配置。
  • 发布一致性：版本号单一来源贯穿 exe 信息 / zip 命名 / 清单 / 安装器；CI 测试与构建分离、依赖版本固定。
  • 鼠标交互：HoverWash/Shimmer/过渡层均设鼠标穿透；嵌套 effect 规避逻辑有效（离屏高 DPI 实测无图标缩放问题）。
